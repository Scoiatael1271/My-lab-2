Task Manager
Простое приложение для управления задачами.
Запуск
1. Установите Python 3.x
2. Запустите gui.py:
python gui.py
Как пользоваться
1. Введите название задачи
2. Введите описание
3. Укажите срок в формате ГГГГ-ММ-ДД (например 2025-12-31)
4. Нажмите «Добавить задачу»
5. Чтобы удалить — выберите задачу в списке и нажмите «Удалить задачу»
Задачи автоматически сохраняются в файл tasks.json.
Структура проекта
classes.py — классы Task и TaskManager
gui.py — графический интерфейс
tasks.json — файл с сохранёнными задачами
README.md — этот файл

Функциональность

- Добавление задач
- Удаление задач
- Автосохранение в JSON
- Загрузка задач при запуске
